# MARS-OPS: Emergency Protocols

This document details the specific emergency types and resource management rules for the **MARS-OPS** simulator.

---

## Emergency Types & Specifications

### 1. Oxygen Leak
* **Human Responder:** Engineer
* **Robot Responder:** Repair Unit
* **Required Resources:** 4 Repair Units

### 2. Fire
* **Human Responder:** Medical Officer
* **Robot Responder:** Repair Unit
* **Required Resources:** 10 Medical Supplies

### 3. Rover Breakdown
* **Human Responder:** Engineer
* **Robot Responder:** Repair Robot
* **Required Resources:** 2 Spare Parts
* **Note:** If available, create a repair mission to service the rover.

### 4. Medical Emergency
* **Human Responder:** Medical Officer
* **Robot Responder:** Rover
* **Required Resources:** 5 Medical Supplies
* **Note:** Check if the affected facility is operational before dispatch.
